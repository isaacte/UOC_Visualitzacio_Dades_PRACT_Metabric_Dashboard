# MetabricUocViz

The dataset used in this project corresponds to the METABRIC study (Molecular Taxonomy of Breast Cancer International Consortium). This dataset contains information on clinical data and genomic sequencing of more than 2,000 patients with breast cancer, providing a global view of this disease. It allows crossing the classic variables of pathological anatomy with the newest molecular classifications.

It is publicly accessible from: https://www.cbioportal.org/study/summary?id=brca_metabric

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
